    • self.__post(msg) — sends a SyscallRequest to the host
    • inbound { __mithic_init: ProcessInit, ports: Transferable[] } — stores the boot object for guest delivery
    • inbound { __mithic_run: string } — evaluates guest code; calls its default export with boot if available, otherwise falls back to calling __mithic_main() for backward compatibility
