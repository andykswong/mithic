    allow?: NetworkAllowEntry[]

    Host allowlist shared by both /dev/tcp and /dev/udp (see NetworkDeviceFsProviderOptions.allow). Derive it from the spawning process's net capability origins via netOriginsToAllow. Omit to mount UNGATED devices (only safe when the mount site otherwise restricts the /dev/tcp+/dev/udp subtree, e.g. via the kernel fs capability).
