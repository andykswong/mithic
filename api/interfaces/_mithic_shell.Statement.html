    OptionalstageNodes

    stageNodes?: Statement[]

    Pipeline: general stages as full command nodes, present when ANY stage is a compound command (subshell/group/if/while/for/...). When set, the executor runs stages in-process (capturing each stage's stdout for the next's stdin) rather than via the kernel spawn fast path. Mirrors stages for the all-simple case to keep one code path.
