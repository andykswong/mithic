    OptionalspawnCoproc

    • spawnCoproc?(params: SpawnParams): Promise<CoprocHandle>

      A2: start a coproc. Mints two kernel pipes (c2s, s2c) and spawns params as a child whose stdin reads the shell's writes (s2c) and whose stdout the shell reads (c2s) — via port-injecting process/spawn (fds:{0:dup2,1:dup2} + transferred portFds). Returns the live duplex handle. Requires a transferable backend; rejects with code:'ENOSYS' otherwise. Absent on minimal mocks.

      Parameters

      • params: SpawnParams

      Returns Promise<CoprocHandle>

    OptionalspawnStream

    • spawnStream?(params: SpawnParams): Promise<SpawnStreamHandle>

      A1: optional live-stream spawn. Spawns a single command whose stdout is a kernel-minted pipe transferred back to the shell as a ReadableStream (process/spawn with fds:{1:{action:'pipe'}}). The real KernelClient provides this on transferable backends; on relay backends it returns a handle with stdout: undefined so the caller falls back to buffered spawn. Absent entirely on minimal mocks (the executor then uses spawn).
